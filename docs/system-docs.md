# System documentation (in-portal)

The authoritative school/system documentation for leadership and engineering handoff lives **inside the web portal**:

- Reader: `/system-docs` (signed-in users always; guests only when Super Admin publishes)
- Super Admin publish control: `/superadmin/system-docs`

Markdown sources: `resources/system-docs/{locale}/{slug}.md`  
Catalog: `config/system_docs.php`  
UI chrome: `lang/{ar,en,fr}/system_docs.php`

The older file `docs/client-system-overview.md` remains a repo snapshot; prefer the portal for briefings.
