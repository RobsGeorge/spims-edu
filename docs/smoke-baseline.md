# Smoke Baseline

Generated by `tests/Feature/Smoke/PublicSurfacesSmokeTest.php` (Step 0).

Test environment: `DB_CONNECTION=sqlite DB_DATABASE=:memory:`, `SEED_DEMO_DATA=false`, `SEED_SAMPLE_DATA=true`.

The smoke test asserts HTTP < 500 for every GET route in `routes/web.php`.
Routes listed below returned 404 (missing fixture) or were excluded from automated
testing because they require fixtures that are not reliably created by the seed that
runs in the test environment.

A 404 row is **not a regression** — it means the route is correctly guarded and simply
has no seed data.  A 5xx row would be a regression.
