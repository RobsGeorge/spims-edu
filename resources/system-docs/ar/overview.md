## ما هو SPIMS

SPIMS نظام مستقل لـ**معلومات الطلاب (SIS)** و**إدارة التعلّم (LMS)** لمدرسة Spims القبطية الأرثوذكسية عبر الإنترنت. المنتج لمدرسة واحدة — وليس منصة متعددة المستأجرين — ويعمل كموقع متجاوب مع الجوال (لا يوجد تطبيق أصلي منفصل في هذا الإصدار).

يتقدّم الطلاب بطلب، يلتحقون، يتعلمون أسبوعًا بأسبوع، يؤدّون امتحانات موقوتة، ينضمون لحصص Zoom المباشرة، يدفعون الفواتير، ويستلمون كشوف درجات أو شهادات يمكن التحقق منها علنًا. ويدير الموظفون القبول والمناهج والتدريس والدرجات والبث المباشر والمالية، مع سجل تدقيق للتغييرات المهمة.

| القدرة | التفاصيل |
|---|---|

| المظهر | فاتح، داكن، أو حسب الجهاز |

| الأجهزة | متصفح على الهاتف والجهاز اللوحي وسطح المكتب — شريط جانبي على الحاسوب وشريط سفلي على الهاتف |

## جملة واحدة

يمكن لطالب إنشاء حساب بالعربية، والتقدّم لبرنامج، والالتحاق، والدراسة أسبوعًا بأسبوع، وأداء امتحان موقوت، والانضمام لحصة Zoom مباشرة، ودفع فاتورة، ثم استلام كشف درجات أو شهادة يمكن لأي شخص التحقق منها برابط عام.

## ملخص القدرات

| المجال | ما يدعمه النظام |
|---|---|
| **الهوية** | مصادقة OTP، أدوار متعددة، تفضيل المظهر، هوية المدرسة |
| **الأكاديميا** | برامج، مقررات، متطلّبات سابقة، اهتمامات، مخططات درجات، قوالب، ترجمات |
| **العروض** | سنوات/فصول، دفعات أو ذاتي الوتيرة، أسابيع/عناصر، بوابة محتوى، تسعير إقليمي |
| **القبول** | نماذج طلب ديناميكية، طابور مراجعة، قبول/انتظار/رفض، تسجيل في البرنامج |
| **التسجيل** | نوافذ التسجيل، قائمة انتظار، حجز مالي، انسحاب، تدقيق درجة |
| **المالية** | فواتير، محفظة بأربع أرصدة، PayPal/Paymob/Cashier، دفع مجزّأ، إيصالات، تبرعات |
| **التقييم** | بنوك أسئلة، مشغّل امتحان (حفظ تلقائي ومؤقت خادم)، اقتراح ذكاء اصطناعي للمقال، واجبات |
| **دفتر الدرجات** | مكوّنات موزونة، قفل المدرّس، إعادة فتح أكاديمية، معدّل، سجلات أكاديمية |
| **المباشر** | جدولة Zoom (مضيف واحد)، حضور، تذكيرات |
| **المجتمع** | لوحات نقاش، إعلانات، إشعارات داخل التطبيق (+ بريد) |
| **الوثائق** | كشوف، شهادات برنامج/مقرر مستقل، تحقق عام بـ QR/رابط |
| **المساعدة** | مقالات Help داخل التطبيق (منفصلة عن وثائق النظام هذه) |

المستخدم متعدد الأدوار يحصل على **اتحاد** صلاحيات كل أدواره. تظهر القوائم والإجراءات فقط بما يُسمح به.

## ما يحتاج إعداد المدرسة

التدفقات أعلاه مبنية في المنتج. هذه التكاملات تحتاج بيانات اعتماد حقيقية في الإنتاج:

| المجال | جاهز في المنتج | يحتاج إعداد المدرسة / تقنية المعلومات |
|---|---|---|
| **PayPal / Paymob / Cashier** | موصول؛ مسار تجريبي للتجربة | مفاتيح حيّة للتحصيل الحقيقي |
| **Zoom** | جدولة، نافذة انضمام، حضور، تذكيرات | بيانات تطبيق Zoom لروابط اجتماع حقيقية |
| **البريد** | OTP، قرارات، إيصالات، تذكيرات | خادم بريد إنتاجي لتصل الرسائل للصناديق |
| **Vimeo** | تضمين في مشغّل المقرر | حساب/معرّفات Vimeo للفيديو |
| **S3** | مسارات رفع للمستندات والواجبات والشعارات | تخزين متوافق مع S3 للملفات الإنتاجية |
| **الذكاء الاصطناعي (Gemini)** | مسودة ترجمة + اقتراح درجة مقال | مفتاح Google/Gemini؛ بدونه يعمل الموظفون دون مساعدة |

بدون هذه الأسرار يمكن تشغيل القبول والتدريس والدرجات والمدفوعات **اليدوية** (نقد، تحويل، شيك) من الطرف إلى الطرف.

## ما ليس في هذا الإصدار

خارج النطاق عمدًا — لا يُتوقَّع وجودها بعد:

- إشعارات واتساب
- تطبيقات iOS / Android أصلية (الموقع متوافق مع الجوال)
- حسابات أولياء الأمور
- تعدّد مدارس / فروع (SPIMS مدرسة واحدة)
- مراقبة امتحان صارمة (قفل الكاميرا) — فقط سلامة ناعمة (تسجيل فقدان التركيز)
- مضيفو Zoom متعددون متزامنون (الجدولة تفترض **مضيفًا مرخّصًا واحدًا**)
- موقع تسويقي عام يتجاوز الصفحة الافتتاحية والكتالوج داخل التطبيق

## كيف تراجعونه مع المدرسة

1. افتحوا الإنتاج أو التجربة وبدّلوا اللغة إلى العربية أو الإنجليزية أو الفرنسية.
2. سيروا مسار **الطالب**: كتالوج → طلب → التحاق → مشغّل المقرر → امتحان → محفظة.
3. سيروا مسار **التدريس**: محتوى → تقييم → قفل دفتر الدرجات.
4. سيروا طابوري **القبول** و**المالية** بأدوار الإدارة المناسبة.

يمكن تحميل بيانات تجريبية على بيئة التجربة لجولة موجّهة. الإنتاج يجب أن يستخدم حسابات حقيقية فقط.
