## Parcours étudiant

Cette page suit le chemin étudiant de la première visite aux documents. Tout ce qui suit est disponible dans le produit live lorsque l’école a configuré semestres, offres et (pour paiements/mail/Zoom réels) les intégrations de production.

---

## Découvrir et candidater

- **Page d’accueil** publique et **catalogue de cours** — filtres programme / autonome / gratuit / payant ; recherche par code ou titre.
- **Drapeaux d’intérêt** — marquer les cours souhaités pour un futur trimestre.
- **Aperçu d’offre** — contenu de la semaine 1 visible avant inscription ; titres des semaines suivantes listés.
- **Formulaires de candidature** construits par l’école (texte, dates, choix, cases, fichiers).
- Les étudiants enregistrent des **brouillons**, soumettent et suivent : brouillon → soumis → en revue → accepté / liste d’attente / refusé.

---

## S’inscrire et progresser

Inscription à une offre **cohorte** (semestre) ou **rythme libre**, sous réserve de :

- Fenêtres d’inscription (ouverture / ajout-retrait / retrait)
- Prérequis et appartenance au programme (sauf cours autonomes)
- Plafonds de crédits / cours par semestre
- Capacité de places — le surplus va en **liste d’attente**
- **Blocages financiers** — bloquent l’inscription jusqu’à levée par la finance

L’étudiant peut **abandonner** pendant l’ajout/retrait ou se **retirer** (W) dans la fenêtre de retrait ; les remboursements suivent les règles de l’école. L’**audit de diplôme** montre le progrès requis et optionnel. Le système avertit en cas de conflit d’horaire live.

## Apprendre (lecteur de cours)

- Le **tableau de bord** montre mes cours, la prochaine session live, les échéances proches, un aperçu portefeuille et les notifications récentes.
- Le **lecteur de cours** organise le contenu par **semaines** :
  - Cohorte : déverrouillage par date
  - Rythme libre : déverrouillage en complétant la semaine précédente
- Types de contenu : **vidéo** (Vimeo), **lecture / PDF**, **leçon texte**, **devoir**, **quiz**, **examen**, **discussion**
- Les **annonces** de l’équipe pédagogique apparaissent dans le lecteur
- Marquer une semaine complète et suivre le % de progression

## Évaluer et notes

| Activité | Expérience étudiant |
|---|---|
| **Devoirs** | Rendre un travail, y compris fichiers ; révisions possibles selon le devoir |
| **Runner d’examen** | Tentative chronométrée, autosave, horloge serveur, confirmation avant envoi ; sur téléphone, une question à la fois par défaut |
| **Types de questions** | QCM, vrai/faux, réponse courte, dissertation, appariement, trous, numérique, ordre, fichier |
| **Notation** | Items objectifs auto-notés ; dissertations peuvent recevoir une suggestion IA pour l’instructeur (si IA configurée) |
| **Intégrité** | Soft uniquement — perte de focus journalisée ; pas de verrouillage caméra |
| **Mes notes** | Uniquement les éléments **publiés** ; notes courantes/finales selon le carnet |
| **Relevé** | Dossiers académiques officiels publiés |

## Payer et portefeuille

- L’inscription crée une **facture** (cours gratuits marqués payés automatiquement). Échéance typique ≈ 14 jours.
- **Double devise :** USD et EGP séparés — pas de conversion automatique.
- **Portefeuille** à quatre soldes : argent EGP, argent USD, points EGP, points USD.
- **Paiement mixte :** argent portefeuille + points + passerelle sur la même facture.
- Passerelles : **PayPal** (USD), **Paymob** / **Cashier** (EGP). Le personnel peut enregistrer espèces, virement ou chèque.
- **Reçu** avec numéro de série après paiement ; **dons** avec désignation.

## Cours live et communauté

- Sessions **Zoom** à venir listées ; rejoindre quand la fenêtre est ouverte.
- Rappels (~24 h et ~15 min) in-app et e-mail si le mail est configuré.
- **Forums** — fils, messages, mentions ; la participation peut être notée.
- Présence importée depuis Zoom ou saisie par le staff ; l’étudiant voit sa propre présence si activé.

- Quiconque (y compris un employeur) peut ouvrir un **lien de vérification public** (QR) et confirmer la validité.

## Parcours typique (numéroté)

1. S’inscrire → vérifier l’e-mail avec OTP → définir le mot de passe.
2. Changer de langue si besoin (arabe / anglais / français).
3. Parcourir le catalogue → drapeau d’intérêt optionnel → aperçu d’offre.
4. Remplir et soumettre un formulaire → attendre acceptation / liste d’attente / refus.
5. À l’acceptation (et matriculation si besoin) → s’inscrire à une offre (ou liste d’attente).
6. Lever tout blocage financier → payer la facture (portefeuille / passerelle / espèces vérifiées).
7. Ouvrir le lecteur → terminer la semaine 1 → enchaîner les semaines verrouillées.
8. Rendre les devoirs → quizzes → examen chronométré le jour J.
9. Rejoindre les Zoom planifiés ; participer aux discussions.
10. Voir les notes publiées ; après verrouillage et émission, télécharger relevé/certificat et partager le lien public.
