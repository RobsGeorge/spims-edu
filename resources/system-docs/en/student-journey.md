## Student experience overview

This page walks the student path from first visit through credentials. Everything here is available in the live product when the school has configured semesters, offerings, and (for real charges/mail/Zoom) production integrations.

---

## Discover and apply

- Public **home page** and **course catalog** — filter by program / standalone / free / paid; search by code or title.
- **Interest flags** — mark courses the student wants offered in a future term.
- **Offering preview** — Week 1 content is visible before enrollment; later week titles are listed.
- **Application forms** built by the school (text, dates, choices, checkboxes, file uploads).
- Students save **drafts**, submit, and track status: draft → submitted → under review → accepted / waitlisted / rejected.

---

## Enroll and progress

Register into a **cohort** (semester) or **self-paced** offering, subject to:

- Registration windows (open / add-drop / withdraw)
- Prerequisites and program membership (except standalone courses)
- Credit / course caps per semester
- Seat capacity — overflow goes to a **waitlist**
- **Financial holds** — block registration until finance clears them

Students can **drop** during add/drop or **withdraw** (W) within the withdrawal window; refunds follow school rules. A **degree audit** shows required and elective progress. The system warns if a new enrollment would clash with another live-session schedule.

---

## Learn (course player)

- **Dashboard** shows my courses, next live session, items due soon, wallet snapshot, and recent notifications.
- **Course player** organizes content by **weeks**:
  - Cohort: weeks unlock by date
  - Self-paced: weeks unlock by completing the previous week
- Content types: **video** (Vimeo), **reading / PDF**, **text lesson**, **assignment**, **quiz**, **exam**, **discussion**
- **Announcements** from the teaching team appear in the player
- Mark a week complete and see overall progress percent

## Assess and grades

| Activity | Student experience |
|---|---|
| **Assignments** | Submit work, including file upload; revisions may be allowed per assignment |
| **Exam runner** | Timed attempt, autosave, server-side clock, confirm-before-submit; on phone, one question at a time by default |
| **Question types** | Multiple choice, true/false, short answer, essay, matching, fill-in-the-blank, numeric, ordering, file upload |
| **Scoring** | Objective items scored automatically; essays may get an AI suggested score for the instructor (if AI is configured) |
| **Integrity** | Soft only — leaving the page / focus loss is recorded; no camera lockdown |
| **My grades** | Only **released** items; running/final grades when the gradebook allows |
| **Transcript** | Official posted academic records |

## Pay and wallet

- Enrollment creates an **invoice** (free courses are marked paid automatically). Typical due window: ~14 days.
- **Dual currency:** USD and EGP stay separate — no automatic conversion.
- **Wallet** has four balances: EGP money, USD money, EGP points, USD points.
- **Split pay:** wallet money + wallet points + gateway on the same invoice.
- Gateways: **PayPal** (USD), **Paymob** / **Cashier** (EGP). Staff can record cash, bank transfer, or cheque.
- **Receipt** with serial number after payment; **donations** with a designation.

## Live class and community

- Upcoming **Zoom** sessions listed; join when the join window is open.
- Reminders (~24 hours and ~15 minutes) via in-app notification and email when mail is configured.
- **Discussion boards** — threads, posts, mentions; participation can be graded.
- Attendance may be imported from Zoom or recorded by staff; students can see their own attendance where enabled.

---

## Credentials

- View issued **transcripts**, **program certificates**, and **standalone course certificates**.
- Anyone (including employers) can open a **public verification link** (QR) and confirm the credential is valid.

## Typical journey (numbered)

1. Register → verify email with OTP → set password.
2. Switch language if needed (Arabic / English / French).
3. Browse catalog → optional interest flag → open offering preview.
4. Complete and submit an application form → wait for accept / waitlist / reject.
5. On accept (and matriculation if required) → enroll in an offering (or join waitlist).
6. Clear any financial hold → pay invoice (wallet / gateway / staff-verified cash).
7. Open course player → complete Week 1 → continue through gated weeks.
8. Submit assignments → take quizzes → sit timed exam on exam day.
9. Join scheduled Zoom sessions; participate in discussions.
10. View released grades; after lock and credential issue, download transcript/certificate and share the public verify link.
